# SPA Planner — фронтенд для мок-API «планирование закупок SPA»

Тестовое задание: веб-интерфейс ИИ-помощника планирования закупок для сети Mountain & Sea Spa
поверх готового backend (`mock_api_spa_procurement`, FastAPI, эндпоинты `/api/catalog/*`,
`/api/planning/*`, `/api/chat`).

## Стек
React 18 + TypeScript + Vite, TanStack Query для работы с сервером, Vitest + Testing Library
для тестов. Без сторонней библиотеки для состояния — серверное состояние полностью на React Query,
локального клиентского состояния немного (фильтры, выбранный товар).

## Запуск

```bash
npm install
cp .env.example .env   # укажите адрес запущенного mock-API
npm run dev
```

Backend запускается отдельно из `mock_api_spa_procurement` (см. README этого репозитория):
`docker compose up --build`, API поднимется на `http://localhost:8000`.

## Что реализовано

- **Каталог** (`/api/catalog/products`) — таблица товаров с остатками, средним расходом
  и индикаторами риска (цветная метка по алертам конкретного товара).
- **План закупок** (`/api/planning/procurement-plan`) — разбивка по товарам, проверка
  бюджета (`within_budget`), переключение горизонта 1/3/6/12 месяцев.
- **Алерты** (`/api/planning/alerts`) — список предупреждений с уровнем (error/warning).
- **Бюджеты** (`/api/planning/budgets`) — карточки бюджета по периодам.
- **Чат** (`POST /api/chat`) — форма вопроса, вывод текстового ответа + структурированных
  данных (`data`), если бэкенд их вернул.

## Тесты

`npm run test` — юнит-тесты на компонент каталога (рендер списка, отображение алертов)
и на API-клиент (маппинг ответа в типы). Полного покрытия e2e нет — не успел в рамках
тестового.
